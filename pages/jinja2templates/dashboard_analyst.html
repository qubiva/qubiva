Cloud Analyst requires an LLM provider

Cloud Analyst lets you query your cloud infrastructure using natural language. It connects to the cloud accounts in your project and uses an LLM to translate your questions into live queries — helping you audit resources, review security posture, investigate costs, check compliance, and get actionable recommendations.

Any OpenAI-compatible API endpoint is supported — including OpenAI, Azure OpenAI, Google Gemini, and self-hosted models.

Set cloud_analyst.llm.provider, cloud_analyst.llm.model, and LLM_API_KEY in your app configuration to get started.
